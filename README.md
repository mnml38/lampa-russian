# Русское кино для Lampa

Плагин добавляет в Lampa подборки российских фильмов и сериалов. Для названий, постеров, годов и рейтингов используется сторонний Kinopoisk API Unofficial. Сам API не принадлежит Кинопоиску.

## Подключение

1. Получите личный API-ключ на [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech/).
2. Добавьте в Lampa URL плагина: `https://mnml38.github.io/lampa-russian/plugin.js?v=1.4.3`.
3. Откройте меню **Русское кино** → **Настроить API Кинопоиска** и введите ключ.
4. Откройте нужную подборку. При выборе фильма плагин ищет совпадение в TMDB по названию и году и открывает штатную карточку Lampa. Если совпадения нет или TMDB недоступен в вашей сборке, плагин покажет сообщение.

Ключ сохраняется в локальном хранилище Lampa на устройстве. Не вставляйте его в исходный код и не коммитьте в репозиторий.

## Подборки

- Новые российские сериалы и фильмы — релизы текущего и прошлого года.
- Популярные российские сериалы и фильмы — сортировка по числу голосов.
- Советское кино — фильмы 1920–1991 годов.

Подборки берут только метаданные. API не предоставляет видео и не даёт доступ к подпискам Okko, Кинопоиска или других сервисов. Для просмотра внутри Lampa нужен отдельный источник, на который у вас есть права или доступ.

API неофициальный; перед публикацией или коммерческим использованием проверьте актуальные условия, лимиты и доступность сервиса.

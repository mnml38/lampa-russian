# Русское кино для Lampa

Плагин добавляет в Lampa подборки российских фильмов и сериалов из TMDB. Он использует встроенный в Lampa источник TMDB и не требует отдельного API-ключа.

## Подключение

1. Добавьте в Lampa URL плагина: `https://mnml38.github.io/lampa-russian/plugin.js?v=1.5.0`.
2. Откройте меню **Русское кино** и выберите подборку. Результаты открываются в штатном каталоге TMDB Lampa.

## Подборки

- Новые российские сериалы и фильмы — релизы за последние два года.
- Популярные российские сериалы и фильмы — сортировка по популярности TMDB.
- Советское кино — фильмы 1920–1991 годов.

Подборки берут только метаданные. TMDB не предоставляет видео и не даёт доступ к подпискам Okko, Кинопоиска или других сервисов. Для просмотра внутри Lampa нужен отдельный источник, на который у вас есть права или доступ.

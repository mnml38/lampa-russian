# Русский раздел для Lampa

Плагин открывает экран с горизонтальными подборками российских сериалов и фильмов из TMDB. Используется встроенный в Lampa источник TMDB; отдельный API-ключ не требуется.

## Подключение

1. Добавьте в Lampa URL плагина: `https://mnml38.github.io/lampa-russian/plugin.js?v=1.6.3`.
2. Откройте меню **Русский раздел**. Сначала появятся новые сериалы, ниже — новые фильмы, популярные подборки и советское кино.

## Подборки

- Новые российские сериалы и фильмы — релизы за последние два года.
- Популярные российские сериалы и фильмы — сортировка по популярности TMDB.
- Советское кино — фильмы 1920–1991 годов.

Подборки берут только метаданные. TMDB не предоставляет видео и не даёт доступ к подпискам Okko, Кинопоиска или других сервисов. Для просмотра внутри Lampa нужен отдельный источник, на который у вас есть права или доступ.
